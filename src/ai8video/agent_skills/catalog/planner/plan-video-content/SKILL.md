# 自适应内容蓝图

- 普通短文本只需提炼目标、受众、核心表达、可用依据、独立角度和行动收束；缺失项保持可选，不得虚构。
- 素材丰富时再使用钩子、节奏、冲突、镜头证据、台词证据和内容蓝图等扩展结构。
- 上游已提供镜头语言、台词或知识证据时直接复用，不重复执行旧式画面分析。
- 把规则分成四类：结构硬约束、需要独立审核的约束、创作默认值和审美选项；不得把审美偏好伪装成系统硬约束。
- 每条视频规划只拥有自己的输出；跨阶段引用必须指向明确素材、镜头或文本证据，不能复制出第二套生命周期状态。
- 规划、创作者确认、独立审核和最终交付是不同状态；规划完成不能冒充成片已通过审核。
- Skill 只提供规划策略；数量、字段、权限和有效结果门禁继续以程序代码为准。
